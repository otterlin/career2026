# 115學年度 二年級生涯參訪（僑泰高級中學職業試探）選課系統 部署與使用說明

本系統已完整匯入資料夾內的兩份核心檔案：
1. **《僑泰高級中學生涯發展教育課程內容_20260806.doc》**：共 **15 門**職業試探實作課程（編號 `01` ~ `15`），每門課程每班名額上限為 **2 位**學生。
2. **《生涯參訪名冊.xlsx》**：共 **16 個班級**（八年1班 ~ 八年16班）、**446 位學生**之完整班級、學號、座號、性別與姓名。

## 二、如何部署至 Google 試算表 (Google Apps Script 雲端資料庫)

1. 開啟 [Google 雲端硬碟](https://drive.google.com/)，新增一個空白的 **Google 試算表 (Google Sheets)**，可命名為 `115學年度二年級生涯參訪選課資料庫`。
2. 點選試算表上方選單的 **「擴充功能」 → 「Apps Script」**。
3. 在左側檔案列表點選 **`Code.gs`**：
   - 將原有的空白程式碼刪除，打開本資料夾的 `Code.gs`，全選複製並貼上。
4. 在左側「檔案」旁點選 **`＋` 號 → 「HTML」**：
   - 檔案名稱輸入 **`index`**（注意全部小寫，系統會自動變成 `index.html`）。
   - 將本資料夾 `index.html` 的內容全選複製並貼上，按 `Ctrl + S` 儲存。
5. **初始化試算表資料表**：
   - 在上方工具列函式下拉選單選擇 **`initDatabase`**，點選 **「執行」**（首次執行請依畫面提示完成 Google 帳號授權）。
   - 執行後回到您的 Google 試算表，會自動建立好 4 個工作表：
     - `課程資料`（15 門僑泰高中實作課程與每班上限 2 人設定）
     - `學生名冊與選課`（446 位學生名冊與即時選課狀態）
     - `帳號設定`（導師專屬帳號 `801`~`816` 與管理員帳號 `admin`）
     - `選課紀錄`（所有學生自選、導師勾選、畫卡匯入之時間戳記稽核紀錄）
6. **發布為網頁應用程式**：
   - 點選右上角 **「部署」 → 「新增部署作業」**。
   - 左側齒輪「選取類型」選擇 **「網頁應用程式」**。
   - **執行身分**：選擇 **「我」 (Me)**。
   - **誰可以存取**：選擇 **「所有人」 (Anyone)**。
   - 點選「部署」後即可取得選課系統網址，將該網址提供給學生與導師即可跨裝置同步選課！

## 三、預設帳號與密碼一覽

| 身分 | 登入方式 / 帳號 | 預設密碼 | 權限說明 |
| :--- | :--- | :--- | :--- |
| **學生** | 輸入 **7 碼學號**（如 `1140001`） | 免密碼（亦提供班級座號快速查學號） | 查看本班 15 門課剩餘名額並即時選課／改選（每課每班滿 2 人即鎖定） |
| **八年 1~16 班導師** | **`801` ~ `816`**（例：八年1班為 `801`） | 同帳號（`801` ~ `816`） | 查看本班選課情形、勾選矩陣幫學生選課、輸出本班 A4 畫卡讀卡單、拍照辨識匯入、自訂每班每科人數上限、匯出本班 CSV |
| **資料組管理員** | **`admin`** | **`admin115`** | 可自由切換檢視全校 16 班、管理各班選課與讀卡匯入、自訂每班每科人數上限、查看全校 16×15 即時統計矩陣、匯出全校總名冊 CSV |

> 💡 如需修改導師或管理員密碼，可直接於 Google 試算表的「**帳號設定**」工作表中修改，即時生效。

## 四、以班為單位「光學畫卡讀卡單」與「紙本手填選課號碼單」操作流程

1. **輸出班級專屬 A4 讀卡單 或 紙本手填選課號碼單**：
   - 導師或管理員登入後切換至 **「🖨️ 3. 輸出畫卡讀卡單／紙本手填號碼單 (A4列印)」**（或直接點擊頂部 **「✍️ 列印紙本手填選課號碼單」** 快捷鈕）。
   - 提供兩種紙本模式自由切換（皆支援單班列印或全校 16 班一次列印，以及紙張大小／邊界／縮放比例調整）：
     - **🎯 模式 A：光學畫卡讀卡單（塗黑圓圈 `01`~`15`）**：單張 A4 完整容納全班 1~30 號 × 15 門課程圓圈，四角印有黑色正方形自動定位塊。
     - **✍️ 模式 B：紙本手填選課號碼單（手寫填寫課程號碼 `01`~`15`）**：上半部印有「15 門職業試探課程編號對照暨班級名額畫記統計表（每科限額 2 人檢核格）」，下半部為左右雙欄（01~15 號、16~30 號）加高大格子的「手填選課號碼欄（`【  】`）」與「課程名稱確認／簽名欄」，方便學生直接手寫填入兩碼課程號碼。
   - **紙本手填號碼單收回後快速登錄**：在「模式 B：紙本手填選課號碼單」預覽畫面中，導師可直接在每位學生的選課號碼框輸入 `1`~`15`（按 `Enter` 自動跳至下一號學生並即時檢核 2 人上限），輸入完畢點擊 **「💾 儲存紙本手填號碼選課結果」** 即可一鍵寫入資料庫！
2. **學生或班級統整畫卡／填單**：
   - 若使用光學畫卡單，請學生用深色筆或 2B 鉛筆在自己的座號列將欲選課程圓圈（`01`~`15`）塗黑；若使用紙本手填選課號碼單，則直接於手填欄寫上 `01`~`15` 課程編號。
3. **拍照上傳自動辨識與匯入**：
   - 導師切換至 **「📷 4. 拍照匯入畫卡辨識選課」**。
   - 點選 **「選擇照片 / 開啟手機相機拍照」**（讓讀卡單四角的黑色正方形定位塊完整入鏡）。
   - 系統會自動完成四角定位透視校正與 450 個圓圈格位濃度分析（亦支援切換為 **Gemini AI 視覺辨識**），並在畫面上標示綠框與列出全班辨識預覽表。
   - 若班上有超過 2 人畫記同一門課，系統會自動以紅底標示超額提醒，導師可於預覽表下拉調整後，點選 **「✅ 確認無誤，將辨識結果匯入本班選課資料庫」** 一鍵完成全班選課！

## 五、個人版 Padlet 數位便條與靈感牆 (`padlet_personal`) 功能說明

可從 **[index.html](file:///d:/115學年度資料組/生涯教育/生涯參訪/二年級生涯參訪/index.html)** 頂部導覽列點選 **「📌 數位便條牆 (Padlet)」** 進入，或直接開啟獨立單頁 **[padlet_personal.html](file:///d:/115學年度資料組/生涯教育/生涯參訪/二年級生涯參訪/padlet_personal.html)**：

1. **多牆面管理與自訂欄位**：
   - 內建「📌 個人數位靈感與待辦便條牆」、「🎓 115學年度 僑泰高中職業試探參訪成果與心得牆」、「🗺️ 生涯規劃與專案腦力激盪自由畫布」三組預設牆面，並支援新增／自訂牆面與分類欄位。
2. **4 種版面檢視自由切換**：
   - **📊 看板欄位 (Kanban / Shelf)**：依分類欄位分欄排列，可直接在各欄底部點選新增卡片。
   - **🧱 網格牆面 (Grid)**：響應式三欄卡片牆面。
   - **🖐️ 自由拖曳畫布 (Canvas)**：按住卡片頂部即可在無邊際桌面上任意拖拉擺放位置，或於空白處**雙擊滑鼠**直接新增便條。
   - **📜 時間軸清單 (Stream)**：單欄聚焦閱讀流。
3. **6 款桌布主題與 6 種卡片色彩**：
   - 支援經典軟木塞、星空深藍、清新薄荷綠、暖陽玫瑰、極簡點陣白、暗黑黑板等桌布，以及暖黃、天空藍、玫瑰粉、翡翠綠、紫羅蘭、純白等卡片色彩。
4. **多媒體附件、標籤搜尋與雲端／JSON 備份**：
   - 支援**本機照片自動壓縮上傳與圖片預覽**、**外部網頁書籤連結**、**互動勾選待辦清單 (Checklist)**、**卡片置頂**、**愛心按讚**與**即時留言回饋**。
   - 支援標籤 (`#Tag`) 與顏色快速篩選、關鍵字即時搜尋、**匯出／匯入 JSON 備份檔**，並可點選 **「☁️ 雲端同步儲存」** 將所有牆面與卡片同步寫入 Google 試算表（`佈告欄設定` 與 `佈告欄貼文` 工作表）。
